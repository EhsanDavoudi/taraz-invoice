# سامانه جامع مدیریت و صدور پیش‌فاکتور «تـراز» (Taraz)
### نرم‌افزار کاملاً بومی ویندوز (Native Windows Desktop Application - .NET 9 WPF)

> **وضعیت نسخه:** `v0.1.0-pre-alpha` (نسخه پیش‌آلفا / آزمایشی اولیه - Pre-Alpha / Experimental)

این نرم‌افزار یک برنامه دسکتاپ ویندوز اختصاصی، ۱۰۰٪ آفلاین و محلی (بدون نیاز به مرورگر یا وب‌سرور) است که به طور کامل با زبان فارسی و راست‌چین (RTL) برای مدیریت شرکت‌ها، کارشناسان و صدور پیش‌فاکتورهای تجاری طراحی شده است.

---

## قابلیت‌ها و امکانات کلیدی

### ۱. مدیریت شرکت‌ها (مشتریان طرف حساب)
- ثبت، ویرایش، حذف و جستجوی شرکت‌ها
- فیلدهای کامل شامل نام شرکت، کد اقتصادی، شناسه ملی، شماره ثبت، تلفن ثابت، تلفن همراه، آدرس کامل و یادداشت‌ها.

### ۲. مدیریت کارشناسان با شماره‌انداز مجزا
- **شماره‌گذاری اختصاصی پیش‌فاکتور برای هر کارشناس**: هر کارشناس دارای پیشوند اختصاصی (مثلاً `EXP-REZ-` یا `EXP-MOH-`) و شمارنده پیش‌فاکتور مستقل است.
- با صدور هر پیش‌فاکتور توسط یا برای یک کارشناس، شماره سریال فاکتور آن کارشناس به صورت خودکار یک واحد افزایش می‌یابد.
- امکان تنظیم دستی شماره شروع و پیشوند در هر لحظه.

### ۳. موتور محاسباتی پیشرفته اقلام پیش‌فاکتور
هر سطر فاکتور دارای اقلام زیر با محاسبات بلادرنگ است:
- **شرح کالا یا خدمات**
- **تعداد / مقدار**
- **قیمت خام واحد**
- **درصد تخفیف فروش**
- **مبلغ تخفیف واحد**
- **محاسبه ویژه تقسیم بر ۱.۱**: تیک اختصاصی جهت اعمال فرمول معکوس مالیات بر ارزش افزوده بازار ایران ($\text{Base} = \frac{\text{Price}}{1.1}$)
- **قیمت فروش نهایی (Sell Price)**: محاسبه خودکار قیمت پس از اعمال تخفیف و/یا تقسیم بر ۱.۱
- **مبلغ کل سطر**: $\text{تعداد} \times \text{قیمت نهایی}$
- **خلاصه‌های مالی**: جمع ناخالص خام، مجموع تخفیف‌های اعطا شده، جمع کل قابل پرداخت فاکتور به عدد و به حروف فارسی.

### ۴. ۵ وضعیت پیش‌فاکتور با رنگ‌بندی تفکیک‌شده
1. ⚪ **پیش‌نویس (Draft)**
2. 🔵 **ارسال‌شده (Sent)**
3. 🟡 **در انتظار تأیید (Pending Review)**
4. 🟢 **تأیید شده (Approved)**
5. 🔴 **لغو / باطل شده (Canceled)**
- امکان تغییر وضعیت سریع با یک کلیک.

### ۵. خروجی تمیز اکسل و پی‌دی‌اف (Customer-Facing Clean Export)
- مطابق درخواست: در فایل‌های اکسل و PDF خروجی مشتری، تنها ستون‌های **«ردیف، شرح کالا یا خدمات، تعداد، قیمت فروش نهایی و مبلغ کل»** همراه با جمع کل درج می‌شوند و محاسبات تخفیف و فرمول‌های داخلی برای مشتری پنهان و محرمانه می‌ماند.

### ۶. موتور پذیرش و پر کردن قالب اکسل (Excel Template Engine)
- کاربر می‌تواند فایل قالب اکسل اختصاصی خود (`.xlsx`) را به برنامه معرفی کند.
- نرم‌افزار قالب را باز کرده و استایل‌ها، لوگو، فونت‌ها و رنگ‌ها را حفظ نموده و اطلاعات فاکتور را در تگ‌های متناظر می‌نشاند:
  - `{{INVOICE_NO}}`, `{{DATE}}`, `{{CUSTOMER_NAME}}`, `{{EXPERT_NAME}}`, `{{GRAND_TOTAL}}`, `{{GRAND_TOTAL_WORDS}}`, `{{ITEMS}}` و ...
- دکمه **«ایجاد نمونه قالب اکسل روی دسکتاپ»** برای آموزش و ساخت آسان قالب.
- دارای قالب پیش‌فرض رسمی و شکیل بدون نیاز به معرفی قالب جانبی.

### ۷. چاپ و صدور مستقیم PDF
- پشتیبانی از چاپگرهای ویندوز و **Microsoft Print to PDF** با سربرگ، کادر مشخصات طرفین، جدول اقلام، مبلغ به حروف و جایگاه مهر و امضا.

### ۸. دیتابیس محلی، کپی فاکتور و پشتیبان‌گیری
- داده‌ها در فایل محلی `Data/database.json` ذخیره می‌شوند.
- قابلیت **کپی سریع (Duplicate)** از پیش‌فاکتور قبلی با شماره سریال جدید کارشناس.
- قابلیت **پشتیبان‌گیری (Backup)** و **بازیابی (Restore)** با یک کلیک.

## نحوه اجرای برنامه روی ویندوز

1. **روش اول (فایل اجرایی مستقیم)**:
   - اجرای فایل `Run-App.bat` در پوشه اصلی، یا
   - اجرای مستقیم فایل `bin\Release\net9.0-windows\TarazInvoice.exe`

2. **روش دوم (اجرا با دستور)**:
   ```bash
   dotnet run --project TarazInvoice.csproj
   ```

3. **اجرای آزمون‌های خودکار**:
   ```bash
   dotnet test TarazInvoice.Tests\TarazInvoice.Tests.csproj
   ```
